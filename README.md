# WindowsDuo

WinUI 3 / Win2D 桌面透视虚化实验。捕获主显示器，并在点击穿透的置顶窗口中绘制处理后的桌面。`Ctrl+Alt+D` 开关整屏效果，`--no-overlay` 只显示预览和控制面板。

## 姿态与透视

启动或点击“将当前姿态设为空间参考”时记录参考姿态。渲染只使用俯仰 X：内容绕屏幕底边转动。左右旋转、滚转和铰链开合始终不会改变画面。

坐标约定为 X 向右、Y 向上、Z 朝观察者。观察点距屏幕 E，三维点的正向透视倍率为 `E / (E - z)`：负 Z 的远端缩小，正 Z 的近端放大。HLSL 通过“输出像素射线与内容平面求交”计算逆向纹理采样，不在透视公式中使用绝对角度。只有模糊与变暗使用绝对距离。背面、掠射和眼后交点不采样。

`DuoLensMath` 与 HLSL 使用同一射线求交约定。预览、单遍渲染和两遍模糊均只应用一次投影。显示 DPI 先确定物理尺度，再整体乘画质倍率，因此 0.25/0.35/1.0 倍率不改变几何或屏幕上的散焦强度。

本效果采用固定虚拟视距和参考支点，补偿的是姿态旋转。它没有眼睛/头部跟踪，也不从加速度积分估计平移，因此不能实现任意观察者移动和平板平移下的完整空间锚定。只有加速度计时，还无法观测绕重力方向的旋转。调整系统横竖屏方向后建议重新设置参考姿态；传感器轴当前按设备原生方向解释。

## 构建与验证

用 Visual Studio 打开 `WindowsDuo.slnx`，选择 x64（或设备对应架构）构建。构建会用 Windows SDK 的 `fxc` 重新生成 `Shaders/DuoLens.bin`，需一起部署，不能仅替换 C# 文件。MSIX 签名沿用项目现有配置。

无额外测试框架依赖的数学回归：

```powershell
dotnet run --project Tests/WindowsDuo.GeometryTests.csproj --configuration Release
```

先构建主项目，再运行实际 Direct2D 着色器离屏验证（Windows x64；使用 WARP，不捕获桌面、不打开叠加窗口）：

```powershell
dotnet run --project Tests/WindowsDuo.GeometryTests.csproj --configuration Release --property:GpuChecks=true
```

验证覆盖正反俯仰、远小近大、底边支点、非 X 轴隔离、正反投影往返、高 DPI 与降采样、无效交点、第二遍不重复投影。离屏测试在 96/192 DPI 与 1.0/0.35/0.25 倍率下测量色条实际像素宽度。

实机观察：关闭“演示动画”，稳定持握 Surface 后设置参考姿态，依次做小幅前后倾斜和左右转动，最后回到参考姿态。可暂时把模糊和变暗设为 0，观察直线与透视；正反方向应不同，回到参考姿态应恢复原始清晰画面。旋转超出视野后出现黑色区域是内容平面边界，不会通过拉长边缘补满。
